# Окружение и доступ к цели

## Факт

Домен `*.fly.dev` блокируется на уровне DNS провайдера (A1, Беларусь): резолвер провайдера отвечает
заглушкой `185.61.104.70/.71` вместо реального адреса (заглушка — страница «Доступ ограничен… решение
Министерства информации РБ», HTTP только на 80-м порту). Блокировка — именная, на всю зону `fly.dev`.

Реальный адрес цели: `66.241.125.52` (Fly.io anycast), получается через DNS-over-HTTPS.

## Следствия для тестирования

- CLI-инструменты (curl и пр.) ходят через `config/targets.sh`: `--resolve host:443:IP`, IP кэшируется
  в `.cache/target-ip`, обновление — `scripts/resolve-doh.sh --refresh`.
- Живой браузер пользователя уже обходит блокировку (Secure DNS/DoH включён в браузере).
- Изолированный Playwright-контур при необходимости запускается с `--host-resolver-rules` — без админ-прав.
- На машинах без блокировки тот же харнесс работает без изменений (привязка IP безвредна).

## Что НЕ является дефектом продукта

Недоступность `*.fly.dev` с этой машины — ограничение окружения (фильтр провайдера), не баг сайта.
В отчёты это попадает только как примечание к среде тестирования.
