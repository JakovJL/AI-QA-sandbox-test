## Предусловия

- Доступны витрина, `/app`, Store API (publishable key), Admin API (токен).

## Шаги воспроизведения

1. Запросить заголовки `Strict-Transport-Security`, `Content-Security-Policy`, `X-Frame-Options`, `X-Content-Type-Options` на: страницах витрины (`/dk`, `/dk/store`, `/dk/cart`, 200 и 404), `/app`, Store API (`/store/products`: 200/400/401/500), Admin API (`/admin/products`: 401/200).
2. Встроить `/dk` и `/app` в iframe на стороннем origin (Playwright `page.setContent` + ожидание загрузки).
3. Запросить `http://<host>/dk` (порт 80).

## Ожидаемый результат

- Все четыре заголовка присутствуют (R-007).
- Страницы не встраиваются в чужой iframe (XFO/CSP `frame-ancestors`).
- HTTP перенаправляется на HTTPS.

## Фактический результат

- Заголовки **отсутствуют на всех проверенных поверхностях**; исключение — Express-404 `/store/<unknown>` (отдаёт `CSP: default-src 'none'` и `X-Content-Type-Options: nosniff`).
- Кликджекинг подтверждён: `/dk` (body 258 символов) и `/app` (body 113 символов) рендерятся внутри iframe.
- `http://<host>/dk` → соединение закрывается без ответа (`socket hang up`), редиректа нет.

## Артефакты

- Проверки: `tests/nfr/security-headers.spec.ts` (NFR-SF-1, NFR-API-1/2, NFR-ADMIN-1 — fail; NFR-CORS-1 — pass), `tests/nfr/security-perimeter.spec.ts` (NFR-PERI-1, NFR-PERI-2 — fail).
- Сырые улики: `reports/artifacts/nfr-headers/{storefront-pages,store-api-200,store-api-errors,admin-surfaces,cors}.json`; `reports/artifacts/nfr-perimeter/{clickjacking,http-redirect}.json`.

## Примечания

- Контроли (чисто): CORS не отражает чужой Origin и не отдаёт credentials; TRACE — не 200; служебные пути `/.git/config`, `/metrics`, `/debug`, `/server-status` не раскрываются.
- HSTS на `*.fly.dev` может добавляться HSTS-preload браузера/CDN, но на origin заголовка нет.
- Отсутствие CSP — прямая предпосылка для XSS-эксплуатации и UI-redress (админ-логин фреймится).
