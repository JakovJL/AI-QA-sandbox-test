# BUG-019: Корневые несуществующие «файловые» пути отдают HTTP 200 и HTML витрины вместо 404

| Поле | Значение |
|------|----------|
| ID | BUG-019 |
| Область | HTTP-семантика / SEO (риски 10, 12); расширяет TC-003 |
| Severity | Low |
| Priority | P3 |
| Слой | UI (маршрутизация витрины) |
| Окружение | `sandbox-session-cand-c26fa443df2a4d52ba4c0f61ea385fac.fly.dev`, 28.09.2026; HTTP-клиент харнесса (контур Б) |
| Воспроизводимость | всегда (NFR-PERI-3 — падает на `/.env`) |
| Статус | Confirmed (внесён в реестр 28.09.2026) |
| GitHub Issue | [#19](https://github.com/JakovJL/AI-QA-sandbox-test/issues/19) |

## Предусловия

- Доступна витрина.

## Шаги воспроизведения

1. `GET /.env`, `/.gitignore`, `/package.json`, `/www.env`, `/.hidden`, `/robots.txt`, `/sitemap.xml`, `/openapi.json`.
2. Для сравнения: `GET /.git/config`, `GET /dk/nonexistent-route-xyz`.

## Ожидаемый результат

Несуществующий ресурс → 404 (отсутствие), либо корректная отдача реального ресурса (robots/sitemap). Основание: R-004/R-005; эталон — `/dk/nonexistent-route-xyz` (404).

## Фактический результат

- `/.env`, `/.gitignore`, `/package.json`, `/www.env`, `/.hidden`, `/robots.txt`, `/sitemap.xml`, `/openapi.json` → **HTTP 200** `text/html` — HTML витрины (title «Medusa Next.js Starter Template»). Содержимое файлов не отдаётся (утечки нет).
- Контроли: `/.git/config` → 404; `/dk/nonexistent-route-xyz` → 404; `/health` → 200 «OK» (ожидаемо, Medusa); `/metrics`, `/debug`, `/server-status`, `/healthz` → 307 на `/dk/*`.

## Артефакты

- Проверка: `tests/nfr/security-perimeter.spec.ts` (NFR-PERI-3 — fail).
- Улики: `reports/artifacts/nfr-perimeter/path-probes.json`.

## Примечания

- Статус 200 для несуществующих путей вводит в заблуждение клиентов/сканеры/SEO и маскирует битые ссылки (тот же класс, что soft-404 BUG-006 и TC-003).
- Утечки секретов не подтверждено: тела — HTML-шаблон, содержимое `.env` не отдаётся.
